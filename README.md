# Learning001

This is a description for the Readme file


| Action     | Meaning                                          | Where it happens       |
| ---------- | ------------------------------------------------ | ---------------------- |
| **Pull**   | Download other people’s latest changes           | GitHub → your computer |
| **Commit** | Record a snapshot of your changes with a message | On your computer       |
| **Push**   | Upload your commits to GitHub                    | Your computer → GitHub |
| **Merge**  | Combine changes from one branch into another     | Locally or on GitHub   |
